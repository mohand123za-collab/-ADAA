# مشروع أداء (ADAA)

موقع متابعة الأداء التعليمي، منشور كصفحة ثابتة على GitHub Pages، ويتصل بخدمة Supabase API.

## خريطة الملفات

- `index.html`: هيكل الصفحة وروابط ملفات الواجهة.
- `src/styles.css`: تنسيقات الموقع.
- `src/core.js`: الحالة العامة، أدوات التنسيق، الاتصال بواجهة API وإدارة الفصول.
- `src/branding.js`: شعارات المعهد المستخدمة في الواجهة والتقارير.
- `src/layout.js`: التنقل، غلاف التطبيق، تسجيل الدخول والإعداد الأولي.
- `src/pages/`: عرض لوحة التحكم والمدرسين والملفات والتقييمات والتقارير.
- `src/modals.js`: نوافذ إضافة وتعديل المدرسين والتقييمات والتفاصيل.
- `src/events.js`: أحداث النماذج والأزرار، التحديث الدوري، وتشغيل التطبيق.
- `supabase/functions/adaa-api/`: واجهة API الخلفية.
- `supabase/migrations/`: تغييرات قاعدة البيانات.

## ترتيب تحميل JavaScript

تُحمّل الملفات من خلال وسوم `script` في أسفل `index.html`. يجب أن يبقى `core.js` و`branding.js` قبل الملفات التي تستخدمهما، وأن يبقى `events.js` أخيرًا لأنه يربط الأحداث ويبدأ التطبيق.

## النشر

تحديث ملفات الواجهة على الفرع `main` ينشر الموقع عبر GitHub Pages. تعديلات واجهة API أو قاعدة البيانات تحتاج نشرها على Supabase وفق إعدادات المشروع.
